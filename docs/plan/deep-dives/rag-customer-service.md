# Deep Dive：RAG 智能客服

## 1. 目标与边界

目标：回答售后政策、物流规则、商品说明类问题，**有依据**。  
非目标：替代完整人工客服工单系统；不保证法律承诺话术自动生效。

## 2. 流水线

```text
文档 → 切片(chunk) → Embedding → Milvus kb_emb
用户问题 → Embed → TopK chunk → Prompt(含片段) → LLM → 答案 + citations
```

## 3. Prompt 原则

- 仅依据提供的资料回答  
- 资料不足明确说不知道/转人工  
- 输出引用编号与 chunkId  
- 禁止编造订单状态（订单类走工具查询，二期可做 Agent）  

## 4. 幻觉治理

| 手段 | 说明 |
|------|------|
| 强约束 Prompt | 拒答策略 |
| 引用强制 | 无引用不展示「确定」语气 |
| 检索阈值 | 低分片段丢弃 |
| 评测集 | 回归防回退 |
| 人工审核知识 | 管理端发布流 |

## 5. 安全

- Prompt 注入：用户输入与系统指令分隔  
- 敏感信息：不把其他用户订单塞进上下文  
- 限流：按用户/IP；LLM 成本熔断
