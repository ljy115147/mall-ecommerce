# ADR-0003：超时关单采用扫描 Job + Kafka 事件

- 状态：Accepted
- 日期：2026-07-16

## 背景

Kafka 无原生延迟队列；需要可靠关单与支付回调竞态处理。

## 决策

订单写入 `pay_deadline`；XXL-JOB 扫描到期订单；发送关单事件；关单逻辑幂等（状态 CAS）；另有补偿扫描。

## 备选方案

1. Broker 延迟插件/时间轮 Topic：运维与一致性叙述更绕。  
2. 纯定时扫库不发事件：不利于多下游。  

## 后果

可补偿、可观测；扫描压力需分片/游标优化。

## 验证方式

不支付订单自动关单；支付与关单并发无脏状态。
