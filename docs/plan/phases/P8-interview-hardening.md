# P8 — 面试硬化与收官（Month 23–24）

## 目标

任何人（包括面试官）按文档能理解你的系统；你能脱稿深挖；演示环境稳定可重置。

## Month 23 — 材料

- [ ] 重绘对外架构图（少字、层次清）
- [ ] 对内架构图（Topic、表、服务依赖）
- [ ] 填满 `interview/hard-questions.md` 与答案要点
- [ ] `interview/stories.md` ≥ 10 个故事（含数据）
- [ ] `interview/resume-bullets.md` 定稿
- [ ] 15 分钟 / 45 分钟演示脚本
- [ ] 已知问题与未来演进（展示判断力）
- [ ] 代码地图：`docs/code-map.md`（关键类路径）

## Month 24 — 模拟与冻结

- [ ] 模拟面试 ×3（不同朋友/录音自审）
- [ ] 一键重置演示数据脚本
- [ ] Tag `v1.0-interview`
- [ ] 最终压测/对账/混沌报告打包 `docs/release/v1.0/`
- [ ] 个人复盘：5 个关键决策；若重来会改什么

## 演示环境硬化 Checklist

- [ ] 冷启动文档 ≤ 30 分钟（已有中间件镜像缓存可放宽）
- [ ] 演示账号表（买家/商家/运营/只读）
- [ ] 失败自动恢复：常用降级默认安全  
- [ ] 敏感配置不在录屏中泄露  

## DoD

- 模拟面试问题不再出现「讲不清」的核心模块  
- Tag 冻结  
- 简历项目描述与仓库一致
