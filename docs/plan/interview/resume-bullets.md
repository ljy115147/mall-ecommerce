# 简历项目描述（终稿草稿，随项目填充数据）

> 每条 1–2 行，动词开头，带技术点与结果。方括号待填实数。

## 推荐版本（7 条）

1. 设计并实现平台多商户交易中台（订单/支付/退款状态机与费用快照），支撑商家经营与买家完整履约链路，保障改价与售后可追溯。  
2. 自研库存中心（可售/占用/已售+流水），秒杀场景采用 Redis 分桶原子扣减 + Kafka 异步下单，压测下 **超卖=0**，峰值 QPS [X]，P99 [Y]ms。  
3. 基于 Outbox → Kafka 落地拼团成团/失败最终一致，解决高并发参团幂等与超时关团自动退款，保证成团事件仅一次生效。  
4. 搭建 Canal→ES 与商品 Embedding→Milvus 管道，实现关键词-语义混合检索，并在向量故障时自动降级，保障搜索可用性。  
5. 实现多路召回推荐（热门/类目/ItemCF/向量）与 RAG 智能客服（citations+拒答），推荐/AI 与交易链路故障隔离，首页与下单不受影响。  
6. 完成订单分库分表、读写分离与支付三方对账；由模块化单体演进至 Spring Cloud（Nacos/Gateway/Sentinel），落地限流熔级与灰度。  
7. 落地容器化与云原生部署：多阶段 Docker 镜像 + Compose 演示环境，微服务阶段 Kubernetes（Ingress/探针/HPA），CI 构建推送与滚动发布回滚演练。
